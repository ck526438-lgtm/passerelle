Langage des règles 
{
  "id": "ma-regle",              // sert au cooldown et aux journaux
  "name": "Lisible dans l'UI",
  "enabled": true,
  "exclusive": true,             // empêche les autres règles de répondre aussi
  "cooldown_seconds": 120,       // anti-boucle par contact
  "filters": {
    "types": ["text","audio"],
    "text_contains_any": ["devis","prix"], "text_excludes_any": ["urgent"],
    "text_regex": "\\?$", "min_chars": 6,
    "fields": { "isOutsideHours": true, "isNewContact": true }
  },
  "steps": [
    { "action": "transcribe", "as": "transcript" },
    { "action": "llm_extract", "as": "task", "source": "{{transcript}}" },
    { "action": "notion_create_page", "title": "{{task.title}}",
      "date": { "Échéance": "{{task.date}}" }, "continue_on_error": true },
    { "action": "reply", "if": { "path": "task.dueLabel", "op": "exists" },
      "template": "Noté ✅ {{task.title}}" }
  ]
}
Variables : {{text}} {{contactName}} {{firstName}} {{chatId}} {{date}} {{time}}
            {{hour}} {{weekday}} {{isOutsideHours}} {{isNewContact}} {{alertWebhook}}
            plus toute variable créée par "as".
Opérateurs "if" : exists is_empty equals not_equals contains starts_with in gt gte lt regex
Autosauvegarde du fichier : les réglages se rechargent tous les 4 s, pas besoin de redémarrer.

Que peut faire chaque action

Passer en vrai WhatsApp (Cloud API)

  1. Créer une app Meta (type Business) puis activer le produit WhatsApp.
  2. Copier Phone number ID et générer un token permanent.
  3. Renseigner .env : WA_PROVIDER=cloud, WA_PHONE_NUMBER_ID, WA_ACCESS_TOKEN, WA_APP_SECRET, WA_VERIFY_TOKEN.
  4. Exposer le port en HTTPS (Caddy, Cloudflare Tunnel ou le VPS du client).
  5. Dans Meta : webhook https://…/webhook/whatsapp, champ messages.
  6. Envoyer un message réel au numéro : il apparaît dans l'onglet Journal.

Une note vocale reçu après l'abonnement au champ messages se transcrit si OPENAI_API_KEY est renseigné ; sinon l'interface affiche « transcription simulée ».
